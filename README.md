# internet-speed-cli

Небольшой консольный скрипт на Python: последовательно качает заданный URL несколько раз и печатает среднее время запроса, объём данных и скорость скачивания.

## Требования

- Python 3.10 или новее (достаточно стандартной библиотеки, зависимости не нужны)

## Запуск

```bash
python speed_test.py <URL>
```

Пример с «тяжёлой» картинкой с Wikimedia:

```bash
python speed_test.py "https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_rocks.jpg"
```

Опции:

- `-n`, `--count` — число запросов (по умолчанию **10**)
- `--timeout` — таймаут одного запроса в секундах (по умолчанию **120**)

```bash
python speed_test.py -n 10 "https://example.com/large-file.bin"
```

## Что считается

1. Скрипт делает **10** (или указанное в `-n`) **последовательных** HTTP GET-запросов к одному адресу.
2. На каждый запрос дожидается **полного** тела ответа.
3. **Среднее время запроса** — сумма времён всех запросов, делённая на их число.
4. **Общий объём** — сумма размеров всех скачанных тел ответов в байтах.
5. **Скорость скачивания** выводится в двух единицах:
   - **MiB/s** (мебибайт в секунду): `1 MiB = 1024 × 1024` байт;
   - **Mbit/s** (мегабит в секунду): `1 Mbit = 1 000 000` бит.

Формула скорости: `общий_объём_байт / суммарное_время_всех_запросов` (запросы идут подряд, не параллельно).
